Introduction

Read fossil records collected from Naturalis and GBIF.

Base URL: http://localhost 
Use the read-only fossil endpoints to list and retrieve occurrence records. List results support source and scientific-name filters, with paginated responses.

Authenticating requests

This API is not authenticated.

Fossils

List fossil records with optional source/name filters and pagination.

Example request:
curl --request GET \
    --get "http://localhost/api/fossils?source=gbif&scientific_name=Tyrannosaurus&per_page=25" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost/api/fossils"
);

const params = {
    "source": "gbif",
    "scientific_name": "Tyrannosaurus",
    "per_page": "25",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());

Request      

GET api/fossils

Headers

Content-Type        

Example: application/json

Accept        

Example: application/json

Query Parameters

source   string  optional    

Filter by source. Allowed values: naturalis, gbif. Example: gbif

scientific_name   string  optional    

Filter by a scientific name containing this text. Example: Tyrannosaurus

per_page   integer  optional    

Number of records per page (1-100). Defaults to 15. Example: 25

Return one fossil record by its UUID.

curl --request GET \
    --get "http://localhost/api/fossils/architecto" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost/api/fossils/architecto"
);

const headers = {
    "Content-Type": "application/json",
